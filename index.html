INTEGRACIÓN PERSONAL

Datos para comprender el descanso y la actividad.

Cuerpo de David es una herramienta de uso personal para consultar datos propios de Oura y preparar su análisis junto con registros de entrenamiento.

Cómo funciona

El titular autoriza el acceso desde Oura. Un conector ejecutado en su propio Mac consulta los datos cuando se solicita una descarga. Este sitio solo ofrece información: no inicia sesiones, recibe autorizaciones ni muestra datos de salud.

Alcance

Por decisión del titular, la configuración solicita todas las categorías habilitadas: Email, Personal, Daily, Heartrate, Tag, Workout, Session, SpO2, Ring Configuration, Stress y Heart Health. La disponibilidad efectiva depende de la cuenta, el dispositivo y la API. No modifica los registros de Oura.

Uso personal

No se ofrece un servicio a terceros. Esta aplicación es independiente y no está afiliada ni respaldada por Oura. La activación de cada instalación requiere registro y autorización del titular.

Sitio informativo. No contiene datos de salud ni credenciales.
